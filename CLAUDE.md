# Projektregeln

- Reine Übersichtsseite (https://mitlaeuferfotografie.github.io/), keine eigene Anwendungslogik, kein Build-Schritt.
- Design: neutrales Dunkelgrau „Graphit“ #232326, minimalistisch (große Systemschrift, Fachfarben Musik #fbbf24, Deutsch #fb7185, Mathe #2dd4bf als Akzent), Meta-Zeile „Klasse · Thema“.
- Keine externen Ressourcen (keine Google Fonts, CDNs, Tracking), nur Systemschriften.
- Impressum/Datenschutz-Link im Footer nicht entfernen.
- Neue App: Karte im passenden Fach-Abschnitt in `index.html` ergänzen (Screenshot 900×600 JPG in `assets/`, Zeile „Klasse · Thema“, Titel, ein Beschreibungssatz) und README aktuell halten.
